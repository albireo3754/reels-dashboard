# Instagram Insights client

Dependency-free, read-only client used by the desktop and one-shot headless CLI for the [Instagram insights integration](../../docs/instagram-insights.md). Supports explicitly selected Instagram Login (`graph.instagram.com`) or Unified Login (`graph.facebook.com`), API v27.0 by default. Every caller must specify the expected owner's username. Unified Login resolves that owner through `/me/assigned_instagram_accounts`; it never treats the system-user `/me` as an Instagram profile.

`account()` verifies the owner before media access. `media()` normalizes API timestamps to ISO UTC and rebuilds fixed-origin pagination requests from cursors. `insights()` requests core metrics in one batch and isolates unsupported metrics on an explicit API rejection. Missing, denied, failed and real zero values remain distinct. Authentication, permissions, throttling, network and server failures stop collection without retry. Only HTTP 400 / code 100 permits the existing unsupported-metric probes. Tokens stay in a private class field and are sent only in Authorization headers; network redirects are refused and upstream error messages are not returned.

There is no publishing, OAuth, permission grant, browser-cookie access or scheduling. Credentials, operational data and account-specific defaults do not belong in this package. Both SDK fixture tests and the desktop service/UI tests live in the parent repository. A live owned-account collection was verified separately; identifying evidence stays outside public source.

Primary sources: [Unified Login setup](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-unified-login/get-started?locale=en_US), [authentication and IDs](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-unified-login/authentication?locale=en_US), [media insights](https://developers.facebook.com/documentation/instagram-platform/reference/instagram-media/insights).
