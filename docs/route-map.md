# 촬영 지도와 시간별 동선

콘텐츠에 `route-map-data.json`을 문서 자료로 연결하면 카드에 **촬영 지도 · 동선 보기**가 나타나요. 같은 계약을 따르는 모든 콘텐츠에 사용할 수 있어요.

## 현재 기능

- 저장된 도로·등산로와 촬영 핀을 오프라인 SVG로 표시해요. 지도 API나 타일 요청, 실시간 길찾기를 수행하지 않아요.
- 이전·다음, 촬영 순서 슬라이더, 시간순 목록과 지도 핀 선택이 같은 촬영분을 가리켜요.
- 영상·사진 필터와 위치 불확실 핀 토글이 있어요. 기본 범위 계산은 불확실 위치를 제외하고, 토글을 켜면 지도 범위에도 포함해요.
- 경로는 점선으로 표시하며 입력의 `routeStatus`와 각 구간의 상태를 보존해요. 촬영 점을 실제 이동 GPS 트랙으로 단정하지 않아요.
- 원본은 현재 콘텐츠에 등록된 파일 또는 등록 폴더 내부의 **정확히 같은 파일명**으로 연결돼야 열려요. 원본을 열면 기존 미디어 서비스의 재생용 사본을 사용해요. 이름만 유사한 탐색 이미지를 원본으로 대체하지 않아요.
- 누락·미연결 원본은 화면에 명시해요. 같은 콘텐츠의 지도 문서는 열린 상태에서 30초마다 다시 읽어요.
- 닫기·Escape 후 원래 버튼으로 포커스를 돌려주고 미디어 재생 요소를 해제해요. 390px 모바일 배치도 지원해요.

## 데이터 계약

`src/shared/route-map.ts`의 `RouteMapData` v1과 `parseRouteMap`이 앱 계약이에요. `captureDate`, `timezone`, 시간순 `assets`, 지도 `ways`, 참고 경로 `legs`, 지점 `pois`, `attribution`, `routeStatus`를 사용해요. 좌표는 `[경도, 위도]` 순서예요.

`assets`는 파일명, 현지 촬영 시각 `HH:mm:ss`, video/photo, 길이, 위치, 기록된 수평 정확도, 불확실 여부와 구간명을 담아요. 중복 이름·시각 역전·범위를 벗어나는 좌표·부적절한 길이를 거부해요. 한 문서는 같은 촬영일 기준이며 연속 날짜를 섞으려면 콘텐츠별로 구분해요.

`source`, `thumbnail`과 그 외 알 수 없는 필드는 공통 DTO에서 제거해요. 원본 경로를 읽을 수 있는 권한은 JSON 내용으로 생기지 않아요. 앱의 `LocalRouteMap.mediaByName`만 등록 자료 경계를 통과한 경로를 포함하며, 사이트에는 이 로컬 전용 객체를 동기화하지 않아요.

`src/desktop/route-library.ts`는 현재 콘텐츠에 직접 연결된 파일명 `route-map-data.json` 문서 하나만 읽어요. 복수 문서·symlink·변경된 경로·8MiB 초과 문서는 거부해요. 문서가 없으면 null, 문서가 잘못됐으면 명시적 오류를 반환해요. Photos 보관함을 읽거나 원본을 내보내는 기능을 자동으로 실행하지 않아요.

기존 허용 사용자에게 제공하는 사이트 동기화는 별도 모바일 bridge가 같은 DTO를 투영해요. bridge와 앱의 sanitizer 계약 비교는 `tests/unit/route-map-sync.test.ts`로 확인해요. 기존 공개 snapshot에는 지도가 자동으로 추가되지 않아요. [실제 앱·사이트 적용 검증](route-map-release.md)을 함께 확인해요.

## 검증 — 2026-10-31

- 타입 검사, FSD 경계 검사, 웹·Electron·MCP 빌드 통과.
- 앱 전용 단위 4개: 민감 필드 제거/잘못된 입력 거부, 큰 geometry 범위 계산, 등록 자료 권한·누락·변경·symlink·크기 한계.
- bridge 계약 포함 단위 9개 통과(bridge 소유 테스트 포함).
- 웹 2개: 시간·필터·위치 불확실 토글·포커스 복귀, 합성 실제 video 재생·390px 배치.
- 개발 Electron 1개: 실제 IPC와 등록 JSON 로딩, 합성 파일의 재생, 선택 변경 시 플레이어 해제, 재시작·문서 변경·원본 삭제 후 상태 재조회.
- 합성 자료만 테스트했어요. 개인 촬영 원본의 전체 자동 연결이나 실제 산행 동선의 정확성을 이 테스트가 보장하지 않아요. 패키징·현재 실행 앱 반영과 사이트 production 검증은 통합 작업 기록을 함께 확인해요.

테스트 산출물은 `test-results/route-app-web`, `test-results/route-app-electron`에 있어요.
