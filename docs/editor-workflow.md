# 영상 편집기

Photos 또는 로컬 영상 한 편을 선택한 뒤 자막·장소 안내 묶음·표지를 편집하고 영상과 표지를 함께 내보내는 흐름이에요. 원본 파일과 Photos 보관함은 편집하지 않아요.

## 사용 흐름

1. **촬영 보관함**에서 날짜를 조회하고 그룹을 연 뒤 동영상 행의 **이 영상 편집**을 선택해요. Photos 원본을 앱 전용 작업 폴더로 준비해요. 또는 **영상 편집 → 로컬 영상 열기**로 파일을 선택해요.
2. 재생용 H.264 proxy가 만들어지면 영상을 재생·탐색해요. HDR source의 재생 proxy는 SDR이며, 최종 출력에는 원본 HDR 규칙을 적용해요.
3. 장소명을 입력하고 장소 설명의 테이프·사각 바·핀만 표시 중 하나를 골라요. 기본 배치는 기존 CLI 값을 그대로 사용하고, 수동 배치를 선택하면 장소 안내 묶음의 기준점을 조절해요. 핀 상시 노출과 설명의 시간 구간을 구분해요.
4. 본문 자막의 시작·끝 시각과 한두 줄 문구를 입력해요. 구간은 영상 길이 안에서 순서대로 겹치지 않아야 해요.
5. 표지 배경 시점을 선택하고 훅을 두 줄로 입력해요. 기본 훅·서명은 왼쪽 정렬이며 장소 핀의 중앙 배치와 별개예요. 자동 크기와 큰 글자 템플릿을 선택할 수 있어요.
6. **영상 미리보기 만들기 / 표지 미리보기 만들기**로 실제 출력 엔진의 배치를 확인해요. 재생 창은 원본의 재생 proxy이며 새 오버레이가 실시간으로 합성되는 창은 아니에요. 설정이 바뀌면 이전 합성 미리보기를 무효화해요.
7. **편집 설정 저장**으로 작업을 이어갈 수 있어요. **영상과 표지 내보내기**에서 새 MOV/MP4 파일을 정하면 영상·오디오와 PNG 표지 및 style manifest를 만들어요. 기존 파일을 덮어쓰지 않고 새 이름을 요구해요.
8. 진행률·실패 이유·취소와 결과 폴더 열기를 제공해요. 취소는 실제 프로세스 그룹과 임시 결과를 정리해요. 완료하면 대시보드가 검토 대기로 바뀌고, 이후 설정을 변경해 저장하면 다시 편집 중으로 반영해요.

원본에 이미 합쳐진 자막·핀·음원은 새 편집 레이어로 분리되지 않아요. 편집기에서 입력하는 본문 자막과 게시 캡션은 별개예요. 이번 범위는 기존 단일-source CLI의 편집 흐름이며 다중 영상 연결·컷 타임라인은 구현하지 않았어요.

## 편집 화면의 템플릿 선택과 조정 — 2026-10-28

영상을 열면 재생 화면 오른쪽의 **템플릿 선택과 조정**에서 기존 번호 프리셋을 고를 수 있어요. 1번은 장소 핀만, 2번은 설명 테이프, 3번은 검은 설명 사각 바이며, 4번은 표지 문구 폭 자동 크기, 5번은 2160px 영상폭 기준 185px 고정이에요. 6번은 **서명 있는 팔로우 마지막 장**이에요. 카드는 구성 예시이며 정확한 결과는 같은 출력 엔진의 합성 미리보기로 확인해요.

**템플릿 세부 조정**을 펼치면 영상 장소 안내 묶음, 표지 훅·서명 묶음, 표지 장소 핀을 각각 화면 비율(%)로 이동할 수 있어요. 0은 기존 기본·수동 배치 그대로이며, 양수는 오른쪽·아래로 이동해요. 기본 배치를 해제하지 않고도 상대 이동을 적용할 수 있고, 본문 자막은 따로 유지돼요. 표지 글자 크기를 직접 지정하면 두 줄에 같은 정수 크기(1~185px, 2160px 영상폭 기준)를 적용해요. 165px 등 기존 고정 크기도 사용할 수 있어요. 핀 크기·자막 크기·절대 위치는 기존 각 편집 영역에서 조절해요.

프리셋 선택은 재질 또는 표지 크기 방식만 변경해요. 입력 문구·자막 시간·표지 시점·배치는 보존하며, 표지 프리셋을 선택하면 직접 지정한 글자 크기를 해제해요. 수정 즉시 기존 합성 미리보기를 무효화하고 저장·내보내기에 같은 값을 사용해요. 안전영역 초과는 엔진에서 오류로 알리며 위치를 임의 보정하지 않아요.

이번 변경은 단위 검사29개, 편집 관련 Chromium 검사21개(최종 패널 배치 후 해당2개 재확인), 자체 실행 엔진12개 및 실제 패키징 앱에서 설정 저장·미리보기·영상/표지 출력1개를 통과했어요. 합성 영상만 사용했어요. 현재 실행 중인 앱을 덮어쓰지 않도록 새 번들은 `release/templates/mac-arm64/Reels Dashboard.app`에 만들었어요.

## 데이터와 신뢰 경계

- Photos materialization은 현재 index run·그룹·공개 asset ID·영상 여부를 검증하고 private UUID 디렉터리에 사본을 만들어요. 출력 경로를 renderer가 지정하지 못해요.
- 프로젝트·proxy·작업 데이터는 앱 user-data 아래에 저장해요. source 경로와 metadata는 main process가 소유하고 renderer가 바꾼 source 정보는 사용하지 않아요.
- 재생 URL은 허용된 프로젝트 proxy만 제공하며 byte ranges를 지원해요. file renderer origin만 허용하고 임의 외부 Origin은 거부해요.
- 같은 기존 Python 패키지를 앱에 포함하며, 원래 Obsidian CLI를 자동 수정하거나 런타임에 참조하지 않아요. 새 API adapter, preview-time·progress 지원과 필요한 timing helper만 추가했어요.
- 출력을 위한 설정 snapshot은 실행 시작 시 고정해요. 내보내기 완료 전에 결과를 게시하지 않고 실패·취소 시 생성한 부분 결과를 정리해요. 스타일 manifest의 임시 caption 경로 대신 저장된 프로젝트 설정을 재편집 기준으로 사용해요.
- Sites/공유 웹에서는 로컬 편집 작업을 제공하지 않아요. 공유 대상은 명시적으로 선택한 대시보드 요약이며 영상 원본은 자동 업로드하지 않아요.

## 검증

- 기존 PhotosIndex75개 테스트를 보존했고 editor.materialize 검증을 포함한 Swift95개가 통과했어요.
- TypeScript13개: caption 구간·스타일 입력·stream Range와 기존 파일 접근·저장·동기화 계약.
- 웹58개: 기존42개와 편집기16개. 새 정본 경로에서도 전체58개가22.3초에 통과했어요.
- 자체 실행 engine11개: cue 경계, 실제 preview·cover·render·audio·progress, 잘못된 입력, FSD, HLG→SDR proxy 및 HDR10bit 출력. 한글/공백 임시 경로와 최소 PATH에서 확인했어요.
- 패키징 desktop/editor8개: 기존 IPC6개와 실제 편집2개. 영상·오디오·표지·manifest, 재시작, 실제 렌더 취소, 원본 hash 불변, Range/seek 및 외부 Origin 거부를 확인했어요.
- 실제 Photos handoff1개: 사용자 접근 권한이 허용된 한 영상만 private copy로 가져와 proxy 재생·탐색과 bundled native 경로를 검증했어요. 실제 개인 영상의 최종 내보내기·삭제는 하지 않았고 QA 사본은 정리했어요.

[엔진 빌드·라이선스](editor-engine.md), [웹 QA](editor-web-qa.md), [Electron QA](editor-electron-qa.md)를 함께 참고해요. 현재 번들은 Apple Silicon·macOS15 이상을 기준으로 만들었고, 다른 기기의 Dolby Vision 파일까지 포괄적으로 검증한 것은 아니에요.


## 서명 있는 팔로우 마지막 장 — 2026-10-29

영상 편집에서 6번을 고르면 두 줄 안내 → 팔로우 문구 → 분홍 손글씨 계정 서명을 왼쪽에 배치해요. 장소 핀은 표시하지 않아요. 선택한 영상 시점의 배경을 9:16으로 중앙 크롭하고, **마지막 장 배경 어둡기**를 조절해 글자 대비를 맞춰요. 안내·팔로우·계정은 편집하고 저장할 수 있어요. 계정은 영문/숫자/밑줄/마침표와 선택적인 🌹를 사용해요.

**마지막 장 미리보기 만들기 → 마지막 장 PNG 내보내기**로 1080×1920 이미지를 저장해요. 이 출력에는 장소명 입력이 필요하지 않아요. 영상 뒤에 자동으로 이어 붙이는 기능은 아니에요. 사진만 있는 경우 현재 영상 편집기의 입력은 동영상이므로 해당 사진으로 만든 정지 영상에서 사용할 수 있어요.

기본 안내70/92px·CTA95px·서명48px이며 자동 크기는 긴 문구를 안전영역 안으로 줄여요. 6번의 직접 지정 크기는 다른 표지의 2160px 기준 숫자와 대응하는 비율로 전체 묶음을 조절해요(184가 기본100%). 기존 4·5번의 두 줄 동일 크기 규칙과 구분해요. 긴 문장이나 화면 밖 배치는 명확한 오류로 안내해요.

관련 검사: 단위50개, 웹 템플릿3개, 내장 엔진13개(HDR 포함), 실제 Electron 마지막 장 선택·저장/재열기·미리보기·PNG 출력1개 통과.
