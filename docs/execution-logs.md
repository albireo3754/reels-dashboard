# 로컬 실행 로그

## 범위와 계약

대시보드 SDK/MCP와 앱이 공유하는 영상 처리 서비스가 시작한 작업만 기록한다. 별도로 실행한 Python, 셸, 시스템의 ffmpeg를 탐색하거나 종료하지 않는다. 기존 서비스의 실행·취소 권한과 동작은 유지한다.

1. 실행 전에 작업 ID, 서비스, 목적, 연결된 프로젝트/상위 작업 ID와 시작 시각을 기록한다.
2. 직접 실행한 프로세스의 PID, 진행률, 마지막 갱신 시각과 제한된 진단 출력을 갱신한다. 편집 엔진이 내부에서 실행한 ffmpeg의 PID를 엔진 PID라고 오인하지 않는다.
3. 실제 프로세스 `close`와 종료 코드로 성공/실패를 기록한다. 프로세스 성공은 전체 내보내기 결과의 검증 완료와 다르다. 종료 신호는 별도로 표시한다.
4. 앱 재시작 시 이전 `running` 기록은 `interrupted`로 바꾼다. 이는 관측 연결이 끊겼다는 뜻이며, 해당 OS 프로세스가 종료됐다고 주장하지 않는다. 자동 재실행·PID로 임의 종료하지 않는다.
5. 공통 컴포넌트는 실행 중/종료된 작업, 시각, 진행률, 종료 결과와 진단 출력을 보여준다. 조회 오류는 빈 목록과 구분하고, 조회만으로 작업을 시작하지 않는다.

## 저장

앱 비공개 userData의 `execution-logs/`에 작업별 JSON을 원자적으로 교체한다. 메인 프로세스의 단일 저장소가 소유한다. 파일 권한은 0600, 디렉터리는 0700이다. 원본 미디어나 원고는 복제하지 않는다. 출력은 작업별 마지막 16,000자, 이벤트는 마지막 100개, 종료 이력은 최근 200개만 보존하며 실행 중 기록은 정리하지 않는다. 진행 기록은 최대 초당 한 번 저장하고 종료 시 즉시 반영한다. 알려진 자격증명 형식은 마스킹하며 환경변수나 명령행 전체를 별도로 수집하지 않는다. 엔진의 진단 출력에 포함된 로컬 경로·실패 명령은 보존한다. 이미지/base64나 원고를 담을 수 있는 표준 출력 결과는 복제하지 않는다.

## 구현 순서와 검증

공통 타입·저장소·프로세스 연결 → 영상 서비스 연결 → 공통 로그 화면 순서로 구현한다. 합성 프로세스로 성공/실패/실행 실패/종료 신호/재시작/출력 제한을 검증하고, 대시보드에서 실행 중과 종료 이력의 실제 갱신을 확인한다. 실제 사용자 영상 재처리, 실행 중 앱 교체, 공개 전송은 포함하지 않는다.

## 연결과 사용

- `shared/lib/execution-logs.ts`: 저장·보존·재시작 처리. 시작 기록을 저장할 수 없으면 실행하지 않는다. 실행 중 디스크 오류는 작업을 죽이지 않고 로그 화면에 저장 실패를 표시한다.
- `shared/lib/logged-process.ts`: 명시적으로 등록한 `spawn`/`execFile`만 관측. UTF-8 진단 출력을 제한하고 stdin을 기다리는 비대화형 명령에는 EOF를 보낸다.
- 편집 엔진, 카드뉴스, 재생용 사본(원본을 재생하지 못하거나 iCloud에만 있을 때만), 분석 프레임·모자이크 작업이 하나의 앱 저장소를 공유한다. 코덱스 SDK의 모델 실행 이력은 기존 시스템을 유지한다.
- 앱 메뉴/검색에서 **실행 로그**를 연다. 화면을 열었을 때만 1.5초 간격으로 새 상태를 조회하며 요청을 중첩하지 않는다. 중지는 기존 편집/카드뉴스 작업 화면에서 수행한다. 로그 화면은 시스템 프로세스 종료 권한을 새로 만들지 않는다.
- `shared/ui/ExecutionLogs.tsx`의 `ExecutionLogView`는 개별 기록 표시, `ExecutionLogsPanel`은 공통 목록·필터·갱신을 담당한다.

검증: `tests/unit/execution-logs.test.ts`에서 실행 중 진행, 실제 종료 코드/신호, 실행 실패, 재시작, 보존 상한, 마스킹, 표준입력 EOF, 이미지 결과 제외를 검증한다. `tests/electron/execution-logs.spec.ts`는 실제 합성 영상 처리→IPC 조회→화면 표시/필터→앱 재실행 후 보존을 확인한다. 카드뉴스 영상 내보내기와 보관함 재생 테스트도 공통 실행 경로에서 통과했다. 개발 빌드 기준이며 실행 중인 사용자 설치 앱에는 아직 적용하지 않았다.
