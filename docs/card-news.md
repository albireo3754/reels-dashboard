# 카드뉴스 릴스

사진·실제 촬영 영상 위에 문구를 놓아 만드는 세로 릴스예요. **고르는 종류는3개**이며, 개인 콘텐츠·미디어는 앱 소스에 포함하지 않아요.

## 문구·비교표·마무리

| 카드 종류 | 쓰는 상황 | 필요한 입력 |
| --- | --- | --- |
| 문구 | 도입·설명·요약·행동 안내 | 문구, 필요하면 보조 설명. 한 문장을 크게 보여줄 때만 **크게 강조** |
| 비교표 | 가격·조건·전후 비교 | 제목,3개 열,최대10행,보조 설명 |
| 마무리 | 팔로우 엔딩 | 안내2줄,계정 서명 |

첫 문구 카드의 시작값은 훅이고 나머지는 본문이에요. **역할 선택과 템플릿 선택을 따로 하지 않아요.** 표·마무리로 바꿔도 문구·미디어·시간은 보존해요. 종류를 바꾸면서 필요해진 필드만 보여줘요. 기존 saved-plan의5개templateId는 렌더링용 식별자로 유지하고, 사용자는3종+문구강조만 골라요. 과거 저장본을 자동 재작성하지 않아요.

## 새 영상 만들기

1. **새 구성**에서 제목과 문구를 입력해요.6장의 빈 구성이 준비되며 도입·마무리 스타일은 지정돼 있어요.
2. 각 카드에 **사진 선택** 또는 **영상 선택**을 해요. 영상은 시작 시점과 카드 노출 시간을 정해요. 원본 소리는 사용하지 않아요.
3. 필요한 카드만 **비교표**나 **마무리**로 바꿔요. 문구 카드의 강조는 체크박스로 켜고 끄면 돼요.
4. 글자·행간·좌표 대신 문구와 줄바꿈을 조정해요. **읽는 시간 추천**은 선택 사항이고, 노출 시간은 직접 정할 수 있어요.
5. **카드 미리보기 만들기 → 구성 저장 → MP4 내보내기**로 진행해요. 음악은 준비한 파일을 선택하며 없으면 무음이에요.

1080×1920·30fps·하드컷 출력이에요. 미리보기와 실제 출력은 같은 내장 템플릿 렌더러를 사용해요. 글자가 넘치면 임의 축소하지 않고 오류로 알려줘요. 브라우저는 연습용이며 실제 미디어·저장·내보내기는 데스크톱에서 제공해요.

## 공통 디자인과 저장 경계

- 줄간격은 글자크기×1.5, 본문각주는 마지막줄 아래32px예요. 표는 제목 아래40px, 설명은 표 아래32px로 붙어요.
- 글자크기·행간·자간·좌표의 문장별 변경, 완성 카드 PNG·임의 오버레이 우회는 저장·출력에서 거부해요. 새 요구는 공통 템플릿에서 수정해요.
- 표·서명·각주는 서로 다른 역할의 고정 규격을 사용해요. `src/shared/card-template-presets.json`과 `native/editor-engine/card_templates.py`가 정본이에요.
- 과거 커스텀 구성을 다시 편집하려면 카드 종류를 고르고 글자 없는 원본 배경을 선택해요. 기존 산출물은 삭제하지 않아요.
- 영상512MB·10분, 사진/음악40MB, 카드20장·총180초 제한이에요. 영상 구간이 원본 끝을 넘으면 오류로 알려줘요. HDR은 출력용SDR사본을 만들며 원본은 보존해요.
- 사용자자료는 앱user-data에만 저장해요. 저장revision 충돌·기존 출력 덮어쓰기를 거부하고 진행률·취소를 지원해요.

## 재사용 경로

새 앱: `release/card-news-simple/mac-arm64/Reels Dashboard.app`. 기존 실행 앱을 종료하거나 덮어쓰지 않아요.

저장본 재출력은 `node --import tsx scripts/render-card-plan.mts USER_DATA_ROOT SAVED_PLAN_JSON OUTPUT_MP4`를 사용해요. 콘텐츠마다 렌더 코드를 새로 만들지 않아요. 역할별 추천시간은 검증된 성공 공식이 아니며,6장12초 같은 개별 선택은 새 영상의 강제값이 아니에요.

# 카드뉴스 릴스

사진 또는 영상 위에 정보를 놓고 자동으로 넘기는 세로 릴스를 만드는 데스크톱 기능이에요. 왼쪽 **카드뉴스 릴스**에서 구성·사진·음악·시간을 정하고 1080×1920, 30fps H.264 MP4로 내보내요.

## 사용 흐름

1. 새 구성의 제목과 카드 문구를 입력해요. 기본 6장의 역할은 도입 훅 → 이유 설명 → 대상·변화 → 숫자 비교 → 행동·기한 → 팔로우 안내예요. 카드 추가·삭제·순서 변경을 지원해요.
2. 각 카드의 **사진 선택**에서 JPG·PNG·WebP 파일을 골라요. 사진은 중앙 크롭으로 화면을 채우며, 글자는 왼쪽 정렬로 세로 중앙에 표시해요. 템플릿을 선택하고 문구·배경 어둡기를 조정할 수 있어요. 글자 크기는 템플릿으로 고정해요. 원본은 유지하고 앱 전용 저장소에 미리보기용 사본을 보관해요.
   10/30 후속 정정으로 완성 카드 PNG·커스텀 오버레이 사용은 제거했어요. 배경은 글자 없는 원본을 선택하고, 표·서명은 해당 템플릿의 내용 필드에 넣어요.
3. **읽는 시간 추천 적용**을 누르면 역할과 문구 길이에 따라 노출 시간을 계산해요. 기본 6장은 3 / 3.5 / 3.5 / 6 / 5 / 3초, 합계 24초예요. 시간은 직접 바꿀 수 있어요. 실제 출력은 30fps 프레임 단위예요.
4. 음악 파일을 선택하면 시작 시점·볼륨·반복 여부를 지정할 수 있어요. MP3·M4A·WAV·AAC를 지원해요. 선택 구간이 영상보다 짧으면 반복을 명시적으로 켜거나 시작 시점을 바꿔요. 음악을 고르지 않으면 무음 MP4로 출력해요.
5. **카드 미리보기 만들기**로 화면을 확인하고 **처음부터 재생**으로 카드와 음악을 함께 확인해요. 수정하면 이전 미리보기를 무효화해요. 다른 메뉴로 이동하면 재생을 멈춰요.
6. **구성 저장**으로 앱 재시작 후에도 이어갈 수 있어요. 다른 구성을 열거나 새 구성을 만들 때 현재 수정본을 먼저 저장해요. 저장되지 않은 수정은 별표로 표시해요.
7. **MP4 내보내기**에서 새 파일 이름을 지정해요. 실제 완료 후 결과 폴더를 열 수 있고, 콘텐츠 보드에 검토 대기 자료로 연결돼요. 기존 파일은 덮어쓰지 않아요. 진행률과 취소를 제공해요.

사진 카드는 같은 1080×1920 PNG를, 영상 카드는 같은 영상 사본과 투명 PNG 오버레이를 미리보기·출력에 사용해요. 글자가 안전영역을 넘으면 오류로 알리며 문구·줄바꿈을 조정해요. 문장별 크기를 줄이지 않아요. 전환은 하드 컷이고 사진 줌·팬이나 문구 등장 애니메이션은 없어요. 선택한 영상은 실제 움직임을 유지해요. 음악 마지막 0.25초는 MP4에서 페이드아웃해요. 브라우저 재생은 리듬 확인용이며 이 끝부분 페이드는 출력에 적용돼요.

## 추천과 근거의 범위

2026-10-29 조사에서 첫 화면의 구체적인 약속, 정보량에 맞는 노출 시간, 불필요한 끝부분 축소를 적용했어요. 시간 추천은 **공백 제외 12자/초 + 0.5초**와 역할별 시작값 중 큰 값을 택하고 0.5초 단위로 올려요. 이는 읽기 검사를 시작하기 위한 편집 가정이며 실험으로 검증된 읽기 속도나 바이럴 기준이 아니에요.

박자 맞춤을 선택하면 입력한 BPM을 기준으로 추천 시간을 다음 박자까지 늘려요. 수동 입력 BPM을 사용하며 음원 BPM·첫 강박을 자동으로 분석하지 않아요. 사진 읽는 시간을 박자 때문에 줄이지 않아요. 100~120 BPM, 가사가 적고 리듬이 일정한 구간은 이번 제작의 후보 기준이에요.

유행곡 조회 API·음원 다운로드는 포함하지 않아요. 사용자가 준비한 로컬 음악 파일을 선택해요. 공개 레퍼런스의 음악·사진은 앱에 배포하지 않아요. 콘텐츠별 확정 문안은 콘텐츠 작업공간에서 관리하며 앱 코드에 개인 제작 문안·미디어를 넣지 않아요.

## 저장·출력 경계

- 구성과 선택 미디어는 앱 user-data의 `card-news/` 아래에서 관리해요. 공유 snapshot에는 포함하지 않아요.
- renderer는 임의 파일 경로를 전달하지 못해요. main의 파일 선택 창으로 고른 미디어만 UUID로 참조해요. 저장 revision이 다르면 덮어쓰지 않아요.
- 이미지·음악 선택은 파일당 40MB, 카드 최대 20장·총 180초예요. PNG 프레임은 크기와 총용량을 검사해요.
- FFmpeg는 패키지에 포함된 바이너리로 실행해요. private 작업 폴더에서 준비하고, 목적지의 임시 MP4에서 인코딩한 다음 기존 파일을 덮어쓰지 않는 방식으로 결과를 확정해요. 실패·취소 시 임시 결과를 정리해요.
- 사진·음악 선택, 저장, MP4 출력은 데스크톱에서 제공해요. 공유 웹은 문구·시간·미리보기 연습만 제공하고 서버에 저장하지 않아요.
- 기존 단일 영상 편집기와 MCP 편집 프로젝트 계약은 그대로예요. 이 기능은 독립 카드뉴스 구성 화면이며, 기존 영상의 타임라인을 재편집하는 기능은 아니에요.

## 검증

실행 결과는 TASKS의 카드뉴스 릴스 항목에 기록해요. 관련 자동 검사는 `tests/unit/card-news.test.ts`, `tests/web/card-news.spec.ts`, `tests/electron/card-news.spec.ts`예요. Electron 검사는 합성 사진·음악으로 저장·재시작·재생·MP4의 프레임 수/장면 경계/오디오·출력 보드 연결·원본 보존·덮어쓰기 거부·취소를 확인해요.


## 영상 배경 — 2026-10-30

- 카드의 **영상 선택**으로 MP4·MOV·M4V를 넣고 **영상 시작 (초)**에서 인점을 정해요. 카드 노출 시간만큼 실제 영상이 재생돼요. 구간이 원본 끝을 넘으면 저장·미리보기·출력에서 오류로 알려주며 자동 반복하거나 마지막 프레임으로 채우지 않아요.
- 사진과 영상을 같은 구성에 섞을 수 있어요. 6장·각2초처럼 사용자가 정한 시간도 그대로 출력해요. 원본 소리는 사용하지 않으며 기존 음악 선택 기능으로 BGM을 넣어요.
- 문구·표·서명은 템플릿이 생성한 투명 레이어로 영상 위에 고정돼요. 임의 PNG 오버레이 선택 기능은 후속 사용자 요청으로 제거했어요.
- 영상은 최대512MB·10분을 허용하고 앱 저장소에 1080×1920·30fps·H.264 무음 사본으로 정규화해요. 원본은 변경하지 않아요. HDR 표기가 있는 소스는 SDR로 톤 매핑하며 미리보기와 출력이 같은 사본을 사용해요. 정규화 결과80MB 제한을 적용해요. 사진·음악40MB 제한은 유지해요.
- 기존 단일 영상 편집기 프로젝트와 별개의 카드 구성 계약을 확장했어요. 기존 사진 구성은 변환 없이 열 수 있어요. 새 구성의 `imageId`는 사진·영상 배경 ID, `videoStart`는 영상 인점, `overlayId`는 선택한 PNG ID예요.
- 새 앱: `release/card-news-video/mac-arm64/Reels Dashboard.app`. 실행 중 기존 앱은 교체·종료하지 않았어요.

검증: 타입·FSD·명세 보존·전체 단위51개·웹3개 통과. 개발 Electron의 영상 혼합 테스트에서 인점·움직임·저장·범위 초과 거부·45프레임/1.5초 출력과 마지막 사진을 확인했어요. 기존 사진·음악·취소 테스트는 최초 실행의 오디오 시계 대기 실패 후 단독 재실행에서 통과했어요. 새 투명 오버레이는 웹 픽셀 검사와 실제 콘텐츠 혼합 출력으로 확인했어요. HDR 자동 톤 매핑 코드는 추가했지만 이번 새 영상 혼합 테스트와 실제 콘텐츠 입력은 SDR이에요.
