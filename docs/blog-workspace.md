# 블로그 작업공간

데스크톱의 **블로그** 메뉴에서 기존 프로젝트를 선택한다. 프로젝트 편집에서 원고 Markdown을 `문서`, 사진이 있는 폴더를 `폴더`로 미리 연결한다. 프로젝트가 새로 만들어지지 않는다.

**원고 열기** 후 필요한 텍스트 구간만 선택하고 **선택한 구간 추가**를 누른다. 기록·과거 버전·비공개 메모는 자동으로 본문에 들어가지 않는다. 선택한 구간의 Markdown 소제목과 굵은 글씨는 미리보기에서 표현한다. 복잡한 Markdown 전체 문법을 지원하는 편집기는 아니다. 원고는 읽기만 하며 저장은 앱의 배치 초안에만 적용된다.

기존 `render-spec.md`를 가져오려면 해당 Markdown과 이미지가 실제 들어 있는 폴더를 프로젝트에 연결한다. 이미지 폴더를 선택하고, 원고에서 JSON 코드 블록 전체를 선택해 **선택한 render-spec 가져오기**를 누른다. 가져올 블록 목록을 확인한 뒤 적용한다. 이미지의 상대 경로는 선택한 폴더의 파일 이름으로만 해석하고 실제 읽기와 저장 시 프로젝트에 연결된 경로인지 재검증한다. 외부 URL, 경로 탈출, 심볼릭 링크를 허용하지 않는다. 본문·소제목·정보·출처·이미지·네이버 전용 요소 자리 표시와 부분 강조·주요 크기/색/배경을 반영한다. 사진 묶음이 이미 완성된 이미지라면 한 장으로 보이며 개별 사진 편집은 제공하지 않는다.

블록의 위/아래·삭제 버튼으로 순서를 정하고 **배치 저장**을 누른다. 배치와 스타일은 앱 user-data의 `blog-drafts`에 프로젝트별로 저장하며, 공유 snapshot에 포함하지 않는다. 다른 탭으로 이동해도 저장 전 화면은 유지된다. 프로젝트 변경·재불러오기에서 저장 전 변경은 확인하며, 다른 프로세스가 먼저 저장한 배치는 revision 충돌로 거부한다. 동시 저장은 프로젝트별 잠금으로 거부한다. 앱이 저장 중 비정상 종료되면 잠금 파일이 남을 수 있으므로 저장 프로세스 종료를 확인한 후에만 잠금을 정리한다. 원고와 사진 파일은 수정하지 않는다.

미리보기는 네이버 편집기의 실제 렌더링이 아니다. 지정 글꼴이 기기에 없으면 대체 글꼴을 사용하고, 네이버 지도·질문은 자리 표시만 한다. 외부 게시·네이버 자동 동기화·실제 편집기 이관은 제공하지 않는다. 사진·원고·초안은 공개 소스에 포함하지 않는다.
